# Data Analyst Capstone: Stack Overflow Developer Survey

IBM Data Analyst Capstone Project (Coursera). I collected job and salary data, analyzed the Stack Overflow Developer Survey (65,437 respondents), and presented the results in a PowerPoint report and an Excel dashboard.

## What I did
- Collected job postings by location with a Jobs API (Python)
- Scraped popular programming languages and average salaries (BeautifulSoup)
- Analyzed survey data with Python and pandas: top 10 languages and databases, now vs next year
- Built a 3-tab Excel dashboard: current technology, future trends, demographics

## Key findings
- Python becomes the #1 language next year; Rust and Go enter the top 10
- PostgreSQL is the top database now and next year
- Washington DC has the most job postings (5,316)
- Swift has the highest average salary ($130,801)
